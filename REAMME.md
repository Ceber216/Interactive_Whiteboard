# InteractiveWhiteboard_Project

A multiplayer collaborate whiteboard application build with Python, Tkinker and WebSockets/TCP


## How to run

1. **Start a server** in your terminal using the following command:
    ```bash 
   python server.py

2. **Start a client/clients** in your terminal/terminals using command:
    ```bash
   python client.py

### What you can do in this project:
- **hold** left mouse button to create a line (it will be visible to other clients)
- **press c** to clear everything on the Whiteboard
- **press z** to clear the last line you have created
- when new client joins a Whiteboard the changes of other people will be visible
